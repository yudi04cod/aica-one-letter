One letter for make.fun's "One Letter for Your Day": a single letter A–Z
standing for the word that describes the day. This entry sends Z — the
day of zero sleep, when the coffee ran out before the morning did.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the letter
(exactly one uppercase letter A–Z), and writes the same single byte on
every run.
